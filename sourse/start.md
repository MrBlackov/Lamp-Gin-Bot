# 👣 Первые шаги

## ➕ Созднание персонажа

Чтобы начать полноценно пользоваться ботом отправьте боту команду /newchar для создания персонажа. После этого выбираем пол будущего персонажа.

    include-markdown "char/new.md"

    end="<!--newchar-end-->"

%}

> ❗Это вырезка, если вы хотите поменять имя, фамилию или навыки посмотрите полный гайд по [Созданию Персонажа](char/new.md).
После создания персонажа это будет сделать труднее.

Нажав на кнопку `✅ Согласиться`, вы создадите себе своего первого персонажа.
